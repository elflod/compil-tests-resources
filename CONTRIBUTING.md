# Comment rajouter/modifier des tests ?

Par défaut, pour vous mettre à jour, vous n'avez pas besoin d'autorisations spécifiques. Pour pouvoir effectuer les différentes actions expliquées dans ce fichier, donnez le pseudo/mail associé à votre compte GitHub à Florian, Jordan ou Chloé pour qu'on puisse mettre les droits nécessaires.
